- [ ] Copy/extract the archive on the intended presentation computer.
- [ ] Run `VERIFY_TRANSFER.py --strict` before installing dependencies.

- [ ] Produce the final PowerPoint using `AI_HANDOFF.txt` or `presentation/01-story/SLIDE_CONTENT.md`; the included organisers' PPTX is not your project presentation.
- [ ] Fill the presenter/team/institution fields and the actual repository/demo URL if required. No URL has been created for you.
- [ ] Check the event's slide count, time limit, submission deadline, permitted prior work and AI-assistance disclosure rules. The supplied deck does not specify an HM-01-wide rubric or presentation time.
- [ ] Choose a sharing/submission destination. Upload the ZIP if source is requested, and the finished deck/video separately if requested. Do not submit local credential files added after setup.
- [ ] Keep claims scoped: a working public-data educational prototype; recorded software checks; no validated biological predictions, user study or demonstrated global novelty.
- [ ] Preserve attribution to third-party code, frozen public data and the organiser's supplied problem deck. This archive does not grant additional redistribution rights or introduce a project licence.
