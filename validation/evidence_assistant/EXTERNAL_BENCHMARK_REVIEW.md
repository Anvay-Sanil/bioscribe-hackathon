# External benchmark recommendation: verified scope and adoption decision

Reviewed 24 October 2026. Status: source assessment, not scientific qualification. Research aid, not a prediction of efficacy or safety.

The supplied recommendation names useful resources, but they are not interchangeable with BioScribe's four-verdict molecular assay task. No external benchmark score is a result obtained by BioScribe. The existing 150 provisional development claims and their hashes are preserved.

| Resource | Verified primary source | Adoption decision and limits |
|---|---|---|
| CIViC-Fact | [Authors' repository](https://github.com/creisle/civicfact), [2025 manuscript](https://pmc.ncbi.nlm.nih.gov/articles/PMC12458922/) | Candidate for a separate cancer-variant claim/passage evaluation. Cancer gene/variant, disease and therapy interpretation differs from checking small-molecule assay records. The inspected manuscript distinguishes gold evidence from retrieved evidence and reports up to 85% for the BGE plus fine-tuned Llama pipeline. The pasted 89% must not become BioScribe's comparator score. |
| SciFact | [Authors' repository and data instructions](https://github.com/allenai/scifact) | Candidate for a separate scientific abstract/passage task with SUPPORTS, REFUTES and NEI. It does not supply BioScribe's out-of-scope label, assay reconciliation or decomposition ground truth. Public development labels exist; test labels are withheld. |
| SciClaimHunt | [Authors' paper](https://arxiv.org/abs/2502.10003), [code](https://github.com/SciClaimHunt/SciClaimHunt), [dataset card](https://huggingface.co/datasets/AnshulS/dataset_for_scicllaimhunt) | Candidate training/stress resource. Inspect generation, evidence annotations, leakage and numerical-claim semantics before adoption. Size alone does not establish fit or independent labels for this task. |
| SMA Evidence Graph | [Publisher's dataset card](https://huggingface.co/datasets/SMAResearch/sma-evidence-graph) | Discovery resource only at present. Its card includes LLM-extracted claims, generated hypotheses and computational drug-design outputs. “Quality gated” and a confidence field cannot substitute for independently adjudicated biological truth. Counts differ by snapshot; pin actual files before quoting counts. |
| WithdrarXiv | [Authors' paper](https://arxiv.org/abs/2412.03775) | Useful arXiv withdrawal stress cases. A withdrawn preprint corpus is not a comprehensive biomedical journal-retraction registry. Failure to find a DOI there must never mark a paper eligible. BioScribe continues to require publication-specific status receipts and abstains for unknown/stale status. |
| HallOumi-8B | [Publisher's model card](https://huggingface.co/oumi-ai/HallOumi-8B) | Optional additional context-grounding comparator. The card describes supported/unsupported context verification and reports macro-F1 on its own evaluation, not BioScribe's four-class task. Unsupported does not distinguish contradicted from insufficient evidence. The card lists CC-BY-NC-4.0; the pasted “truly open source” description does not remove those use restrictions. Its confidence scores require local calibration assessment. |

The pasted text also asserts that every resource labels all output as a research aid. This was not established across the resources. BioScribe enforces its own required label independently.

## Concrete evaluation plan

1. **Current molecular-record track:** retain `claims.jsonl` and `proposed_labels.jsonl` as provisional development challenges, never an independent holdout. Use the pinned Qwen3 4B model and identical corpus/retrieval for a same-task exploratory comparator. Complete all 150 predictions and record missing/invalid outputs. Report agreement with draft labels, not demonstrated biological accuracy.
2. **External paper track:** select and pin a specific CIViC-Fact or SciFact release, exact files and hashes, license and required attribution; retain upstream IDs, original labels, publication IDs, evidence sentences and original splits. The repository currently lists multiple 2026 CIViC builds; do not attach a 2025 manuscript score to an unexamined newer build. Acquisition through the GitHub API was rate-limited in this session, so no release is claimed imported, frozen or evaluated.
3. **Mapping review:** SUPPORTS → supported, REFUTES → contradicted and NEI → insufficient_evidence are candidate mappings for a defined paper task only. Do not map clinical claims outside the current product scope to these labels. Preserve original labels separately; define scope annotations independently. HallOumi's binary outputs need a separate binary grounding report or a reviewed adapter, not an invented four-class mapping.
4. **Independence:** keep claims sharing publication, molecular profile, source record or generated parent in a common split as justified by task. Audit train/development/holdout overlap, duplicates and model training exposure. Public benchmarks cannot guarantee absence from foundation-model pretraining. Never select cases based on which system wins.
5. **Qualification:** obtain independent adjudication of source entailment, identity, context, retraction status and scope; freeze the comparison protocol before holdout use. Citation correctness, semantic decomposition and assay disagreement handling need their own reviewed cases. A favorable public leaderboard number cannot close these gates.

The bounded implementation currently abstains on arbitrary paper-passage entailment. Importing a dataset would not activate that capability. The source assessment is actionable preparation for that extension, not evidence that it is implemented.
